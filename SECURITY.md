# Безопасность и приватность

## Если токен уже был отправлен в чат или попал в публичный репозиторий

Считайте его раскрытым. Отзовите GitHub PAT в Settings → Developer settings → Personal access tokens. Перевыпустите Telegram bot token через BotFather. Удаление строки из последней версии файла не отменяет утечку через историю Git. После ротации при необходимости очистите историю и проверьте журнал доступа.

В референсном trenazhor используется клиентский config.js. Не переносите оттуда действующие секреты в этот проект. Любой токен в HTML/JS статического сайта виден посетителю, даже если файл называется config.js, строка закодирована или переменная называется private.

## Правила этого проекта

- Публичный сайт содержит только reportEndpoint — адрес обработчика, не учётные данные.
- TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID хранятся в Cloudflare Secrets.
- Получатель фиксирован в серверной настройке. Клиент не может назначить другой chat_id.
- Клиент не передаёт токен Telegram и не обращается к api.telegram.org напрямую.
- До явного нажатия и согласия ответы не уходят на сервер отчётов.
- Скачивание отчёта не использует Telegram.
- Отчёты не включают GitHub/Telegram-токены, IP-адрес ученика, cookies и содержимое других работ.
- Авторские секреты, файлы .env и .dev.vars нельзя коммитить.

## Что защищено, а что нет

Обработчик ограничивает origin, размер запроса, количество попыток и частоту отправки; повторно считает математику и не доверяет клиентскому баллу. Cache API помогает не дублировать одинаковые отчёты, но кэш локален/вытесняем и не даёт строгой идемпотентности.

**CORS не является аутентификацией.** Origin можно подделать в запросе не из браузера. Rate Limit binding приблизительный и локальный к Cloudflare location. Fallback при установке через Dashboard ещё слабее — на уровне изолята. Для открытой массовой аудитории добавьте Cloudflare Turnstile/авторизацию, отдельный bot и отслеживание злоупотреблений.

Статический тренажёр не может достоверно доказать, что ученик не подсмотрел ответ. Задания и движок доступны браузеру, seed и события можно подделать. Время, подсказки и разборы — учебная телеметрия, не доказательство честности контрольной.

При сетевом таймауте Telegram мог успеть получить файл. Интерфейс предупреждает об этом; перед повтором уточните доставку у учителя.

## Данные ученика

В браузере сохраняются имя/класс, самооценка памяти, текущая работа и последние 20 работ. Удаление локальных данных не удаляет сообщения, уже полученные учителем.

При подтверждённой отправке имя, класс, ответы, попытки, подсказки, разборы, время и необязательный комментарий проходят через Cloudflare в Telegram. Приложение не включает аналитику и не сохраняет отчёты в собственной базе. Хостинги могут вести обычные технические логи обращений. Учителю следует учитывать правила обработки данных несовершеннолетних и пользоваться только необходимыми именами, например именем и инициалом фамилии.
