# Аничков · Формулы сокращённого умножения

Самостоятельная веб-страница для 7–8 класса в тетрадном оформлении по мотивам [BaikovaAlina/trenazhor](https://github.com/BaikovaAlina/trenazhor).

**Быстрый запуск и настройка Telegram без платного сервера: [START-HERE.md](START-HERE.md).**

## Учебные возможности

- 7 формул: квадрат суммы/разности, разность квадратов, куб суммы/разности, сумма/разность кубов.
- Карточки с мнемоникой и самопроверкой памяти.
- Пошаговые объяснения и типичные ошибки; геометрическое объяснение квадрата суммы.
- Базовый уровень с квадратами и расширенный уровень с кубами.
- Выбор правильной формулы, заполнение коэффициента, раскрытие скобок, разложение на множители.
- 10 / 15 / 20 заданий, тематический выбор и работа над слабой формулой.
- Подсказки, исправления, разборы. Отдельная самостоятельная проверка без показа правильности до конца.
- Счёт **с первого раза без помощи**, итоговые верные ответы, самостоятельные исправления и помощь — разные показатели.
- Продолжение текущей работы, последние 20 результатов и удаление локальных данных.
- TXT-отчёт без интернета. Реальная доставка в Telegram — после отдельного бесплатного подключения Worker, только по явному действию и подтверждению ученика.
- Телефон, планшет, компьютер; клавиатурная навигация, reduced motion, непривязанные к цвету сообщения об ошибках.

Отметка «Уже помню» — самооценка, а не доказательство освоения. Тренажёр не является защищённой контрольной.

### Никаких внешних CDN

В готовом HTML встроены WOFF2-шрифты, SVG-иконки, CSS и JS. Страница не загружает библиотеки, аналитику или шрифты с чужих сайтов. Самостоятельно скачанный `index.html` можно открыть без сети. Для первой загрузки опубликованного сайта и отправки в Telegram нужен интернет.

### Проверка ответов

Рекурсивный парсер строит полином с несколькими переменными. Проверка сравнивает коэффициенты одночленов, **не** значения в случайных точках. Нет `eval`, `Function` и сетевого математического API.

Поддерживаются `x²`, `x^2`, `2x`, `2*x`, десятичная запятая/точка, числовые дроби, скобки, несколько переменных и перестановка слагаемых. Русские `х`, `а`, `в`, `с`, `у` нормализуются в латинские аналоги. Есть предел длины, степени и сложности; числовая погрешность сравнения — 1e−8.

Для «Раскрой скобки» недостаточно повторить исходную степень. Для «Разложи» недостаточно вернуть исходный многочлен: проверяется структура преобразования. Это учебная проверка, а не универсальная CAS и не проверка полного разложения над всеми полями.

В экзаменационном режиме можно менять ответы: все сохранённые версии видны учителю. Процент с первого раза не подменяет долю верных итоговых ответов.

## Разработка

Нужен Node.js 20+. Для сборки не требуется `npm install`:

```sh
node scripts/build.mjs
```

Сборка создаёт:
- `index.html` — готовый файл в корне;
- `site/index.html` — та же страница для изолированной публикации;
- `worker/telegram-worker.mjs` — самостоятельный ES-модуль.

Не редактируйте сгенерированный Worker вручную: следующая сборка перезапишет его.

Для локального просмотра с Python 3:

```sh
npm run build
npm run preview
```

Сайт слушает `0.0.0.0:3000`. В браузере откройте `http://localhost:3000`. Клиентский код не обращается к localhost API. Для проверки Worker на localhost явно добавьте `http://localhost:3000` в ALLOWED_ORIGINS; на рабочем экземпляре этот origin оставлять необязательно.

## Настройка Telegram через Wrangler (рекомендуется)

Вариант без команд описан в START-HERE.md.

1. Войдите в бесплатный аккаунт Cloudflare, **Workers Free**. Не включайте платный тариф.
2. Из корня проекта:

```sh
npx wrangler@4 login
npx wrangler@4 secret put TELEGRAM_BOT_TOKEN --config worker/wrangler.jsonc
npx wrangler@4 secret put TELEGRAM_CHAT_ID --config worker/wrangler.jsonc
npm run worker:deploy
```

Если Wrangler попросит сначала создать Worker, выполните `npm run worker:deploy` перед `secret put`, затем добавьте секреты и проверьте `/health`.

3. Укажите настоящий адрес созданного Worker с `/report` в конце в `site-config.json` → `reportEndpoint`.
4. `npm run build`, загрузите обновлённый `index.html` в GitHub.
5. Проверьте реальной учебной работой с опубликованного origin.

Токены передаются через скрытый интерактивный ввод Wrangler, а не аргументы командной строки. `.dev.vars`/`.env` исключены из Git. `ALLOWED_ORIGINS` в `worker/wrangler.jsonc` уже соответствует вашему `github.io`-сайту. Если namespace_id `1001` уже занят другим rate-limiter в вашем аккаунте, выберите другой уникальный положительный числовой идентификатор.

### Что отправляет обработчик

- Принимает только POST JSON с явно подтверждённым согласием, с разрешённых origins.
- Проверяет размер и схему; повторно генерирует задания по seed и настройкам.
- Сам пересчитывает математические ответы и статистику; не принимает клиентский «готовый балл».
- Использует только серверный `TELEGRAM_CHAT_ID`. Ученик не может передать произвольного получателя.
- Отправляет **одно сообщение Telegram с документом TXT**, caption содержит краткий итог.
- Возвращает успех только после `ok: true` и `message_id` от Telegram.
- Имеет приблизительный лимит 12 отчётов/IP/минуту и best-effort дедупликацию через Cache API до суток. Это не абсолютная гарантия уникальной доставки.
- Не печатает токен, отчёты и ответы Telegram в console. Секреты не возвращаются клиенту.

На Workers Free действуют квоты провайдера. Проверено по официальной документации 17.11.2026: https://developers.cloudflare.com/workers/platform/pricing/ . Binding: https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/ . При достижении лимитов не нужно переключаться на платный тариф: можно временно использовать скачивание отчётов.

Браузерный smoke-тест проходит полный сценарий с ошибкой, подсказкой, разбором, восстановлением после перезагрузки, сохранением отчёта и самостоятельной работой. Проверены ширины 360/390/768/1440 px и sandbox без доступа к localStorage. Тест доставки использует **мок**, не реальный Telegram. Сборка Worker проверена Wrangler `--dry-run`; это не публикация.

## Ограничения и данные

- Нет регистрации или синхронизации между устройствами.
- На общем устройстве данные видны пользователям того же браузера.
- LocalStorage может быть очищен браузером. Для важной работы скачайте/отправьте отчёт.
- Учитель видит не весь процесс набора текста, а только ответы, сохранённые кнопкой проверки/сохранения.
- Таймер учитывает активное время в открытом тренажёре, не время скрытой вкладки, теории или диалогов. Данные времени и помощи сообщаются браузером и не защищены от намеренной подделки.
- Защита от массового спама приблизительная; CORS не является авторизацией. Для публичного массового использования добавьте Turnstile или собственную авторизацию.
- Квоты, политика доступности и технические логи GitHub, Cloudflare и Telegram регулируются самими сервисами.

Шрифты распространяются по SIL OFL; тексты лицензий сохранены в `assets/fonts/`.
