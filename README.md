# 📐 Степень PRO — интерактивный тренажёр

Одностраничный тренажёр по **свойствам степеней для 7–8 класса**. Оформление — школьная тетрадь: клетка, поля, карточки-подсказки и понятная обратная связь.

## Что умеет

- **10 формул-шпаргалок**: умножение и деление степеней, степень степени, степень произведения и дроби, нулевой и отрицательный показатели;
- три режима: «Быстрый старт» (10 задач), «Марафон степеней» (18 сложных смешанных задач) и «Ловушки» (12 коварных правил);
- проверка каждого ответа, подсказки и разборы;
- отчёт: точность первой попытки, время, ошибки, введённые ответы и использование подсказок;
- кнопка **«Отправить учителю»**: защищённо отправляет отчёт в Telegram через серверную функцию. Секреты не попадают в код сайта и не видны ученикам.

## Структура

```text
├── index.html                       # страница тренажёра
├── styles.css                       # визуальный стиль «тетрадь»
├── app.js                           # задания и интерактивность
├── netlify/functions/send-results.js# защищённая отправка в Telegram
├── netlify.toml                     # настройки Netlify
└── .env.example                     # только названия секретов, без значений
```

## Публикация и Telegram (Netlify)

GitHub Pages подходит для статичной части сайта, но **не подходит для безопасной отправки в Telegram**: токен бота нельзя размещать в браузерном JavaScript. Поэтому этот репозиторий подготовлен для Netlify.

1. Откройте [Netlify](https://app.netlify.com/) → **Add new site** → **Import an existing project**.
2. Подключите репозиторий `BaikovaAlina/anichkov`.
3. Netlify автоматически прочитает `netlify.toml`. В поле publish directory должно быть `.`.
4. До первого деплоя откройте **Site configuration → Environment variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
   - `TELEGRAM_CHAT_ID` — ID чата учителя.
5. Нажмите **Deploy site**. После этого кнопка «Отправить учителю» будет отправлять имя ученика, режим, результат первой попытки, время и ответы в Telegram.

> Не добавляйте токен бота или GitHub PAT в `app.js`, `index.html`, `config.js` и любые другие публичные файлы. Если токен уже был опубликован, отзовите его через BotFather и создайте новый.

## Локальный просмотр

Статичную страницу можно открыть через любой HTTP-сервер:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Кнопка Telegram локально вернёт статус «Отправка ещё не настроена» — это ожидаемо, потому что функция запускается Netlify и использует секреты из его панели.

## Как редактировать задания

Все задания находятся в массиве `tasks` в `app.js`. Для новой задачи используйте уже существующий шаблон `T(...)`: укажите ответ, подсказку и краткий разбор. Ответы записываются в обычном виде: `x^7`, `a^3/b^2`, `1/8`.
